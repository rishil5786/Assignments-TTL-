## 🛠️ Requirements & Setup

### Prerequisites
- Python 3.8+
- Jupyter Notebook / JupyterLab / VS Code

### Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/rishil5786/Assignments-TTL-.git
cd Assignments-TTL-
pip install numpy pandas matplotlib seaborn scikit-learn tensorflow shap mlflow
```

---

## 🚀 Running the Notebooks
Open the notebooks using Jupyter Notebook or Jupyter Lab:
```bash
jupyter notebook
```
